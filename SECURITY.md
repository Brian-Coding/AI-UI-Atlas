# Reporting a security issue

Do not open a public issue with credentials, private screenshots, or a working exploit against someone else's app.

Use the repository's **Security → Report a vulnerability** option if available. If private reporting is unavailable, open a minimal issue requesting a private contact channel without including exploit details or private data. Send only a sanitized reproduction after a channel is agreed.

Read [the security model](docs/security.md) for intentional provider permissions, loopback services, and artifact handling. This project is a local developer tool, not a hosted multi-user service.
