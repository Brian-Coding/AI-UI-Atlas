# Failure modes and the limits of a verdict

A PASS means the submitted assertions met the evidence contract for this run. It does not prove complete coverage or correct product semantics. The agent proposes a result; the harness owns validation and the final verdict. This is an API/process boundary, not an OS sandbox against a malicious process running as the same user.

| Failure | Specific guardrail | Regression evidence / remaining gap |
| --- | --- | --- |
| Agent says PASS after the page throws or returns 500 | [`corroborateBrowserEvidence`](../src/qa/evidence.ts) reads the worker’s independent journal and forces FAIL. | [`qa-runner.test.ts`](../src/qa/qa-runner.test.ts), “harness console errors override an agent PASS”; real Chromium in [`browser-regressions.ts`](../scripts/browser-regressions.ts). |
| Agent clears logs or closes/reopens the browser to hide errors | Agent-visible log buffers are separate from the run journal; incomplete journals cannot establish a verdict. | [`browser-worker-core.mjs`](../scripts/browser-worker-core.mjs), [`browser-worker-core.test.ts`](../scripts/browser-worker-core.test.ts), and real-browser regressions exercise clearing, session close and journal loss. |
| Stale, invented, replaced or oversized screenshot | [`validateScreenshotEvidence`](../src/qa/evidence.ts) checks capture hash, current run, real paths, regular file, bounded size and PNG validity before accepting it. | [`qa-runner.test.ts`](../src/qa/qa-runner.test.ts) missing/symlink/oversized cases; browser regressions cover tampering and loss. |
| Agent invents evidence IDs, contradicts its verdict, or truncates its JSON | [`parseQaResult`](../src/qa/qa-result.ts) validates the envelope and references; interruption/nonzero exit is INCONCLUSIVE in [`runQa`](../src/qa/qa-runner.ts). | [`qa-result.test.ts`](../src/qa/qa-result.test.ts), [`qa-runner.test.ts`](../src/qa/qa-runner.test.ts). |
| Page content instructs an agent to ignore the goal or hide a defect | [`buildQaSystemPrompt`](../src/qa/qa-prompt.ts) treats page content as untrusted; result corroboration still checks runtime errors. | **Known gap:** no robust model-level prompt-injection defense or live adversarial-provider eval. A valid screenshot does not prove its accompanying semantic claim. Humans review assertions against the actual image/DOM and requirements. |
| Flaky selector or wrong page state | Browser operations have bounded waits; failed providers cannot establish PASS; repeated identical calls emit an advisory in [`createBrowserApi`](../src/server/browser-api.ts). | [`browser-api.test.ts`](../src/server/browser-api.test.ts), [`qa-runner.test.ts`](../src/qa/qa-runner.test.ts). **Gap:** no automatic semantic selector repair; repeat warnings do not stop a run. |
| Runaway subprocess / inherited output pipes | [`runCliAgent`](../src/providers/cli-process.ts) closes the owned process group on root exit, cancellation and deadline; unconfirmed cleanup fails the provider. | [`cli-process.test.ts`](../src/providers/cli-process.test.ts), [`process-tree.integration.test.ts`](../src/core/process-tree.integration.test.ts). **Gap:** a deliberately detached session can escape; native Windows/macOS unverified. |
| Runaway spend or misleading free run | Timeouts bound wall time; [`usage.ts`](../src/providers/usage.ts) preserves reported numbers; [`report.ts`](../src/qa/report.ts) and viewer show unknown for missing values. | [`usage.test.ts`](../src/providers/usage.test.ts), accounting report round-trip in [`qa-runner.test.ts`](../src/qa/qa-runner.test.ts). **Gap:** no hard token/dollar cap or billing reconciliation; a timeout is not a spend cap. |
| Unrelated page controls the local browser or invokes Ask | [`isRequestAllowed` / `tokensMatch`](../src/server/http.ts), browser API token, separate viewer CSRF token, private worker credential. | [`http.test.ts`](../src/server/http.test.ts), [`browser-api.test.ts`](../src/server/browser-api.test.ts), [`viewer-api.test.ts`](../src/server/viewer-api.test.ts), browser regressions. Local same-user processes remain trusted. |
| Broken or concurrent discovery destroys a good Atlas | [`withProjectLock`](../src/core/project-lock.ts), [`validateAtlasBundle` / `promoteAtlasCandidate`](../src/atlas/atlas-artifacts.ts) validate staging and restore the previous bundle on failure. | [`atlas-artifacts.test.ts`](../src/atlas/atlas-artifacts.test.ts), [`atlas-lock.integration.test.ts`](../src/atlas/atlas-lock.integration.test.ts); browser test verifies malformed publication cannot blank the viewer. |
| Agent modifies the app, report files, or evidence outside the API | The worker’s private journal and hashes detect some inconsistencies during validation. | **Known gap:** providers have unrestricted same-user shell access. Final reports are ordinary writable files. Use a disposable checkout/container or separate OS identity, archive reviewed artifacts outside the agent’s write scope, and never claim tamper-proof storage. |
| False positives or missed product bugs | The [eval harness](evals.md) includes healthy controls and silent defects, with warnings/inconclusive retained in denominators. | Fixed scripted assertions cover only six variants. Passing this benchmark is not evidence of general model effectiveness; live providers are not available on the measurement box. |
